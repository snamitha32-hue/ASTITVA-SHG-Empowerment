# ASTITVA – Women's Self-Help Group Empowerment Platform

## About the Project
ASTITVA is a web-based platform designed to empower women belonging to Self-Help Groups (SHGs). It aims to simplify group management, customer order tracking, work distribution and financial record management.

## Key Features
- Separate Leader and Member Dashboards
- Customer Order Management and Tracking
- Smart Work Distribution
- Individual Earnings History
- Payout Management
- AI Group Assistant (planned integration)
- Notifications and Reminders
- Product Catalogue
- Group Announcements

## Technology Stack
- Frontend: HTML, CSS and JavaScript
- Backend: Python FastAPI (development planned)
- Database: SQLite / PostgreSQL (planned)
- AI: AI model integration (planned)

## Project Objective
To provide women Self-Help Groups with a centralized digital platform that improves teamwork, transparency, business management and financial independence.

## Current Project Status
Frontend prototype developed. Backend, database, authentication and AI integrations are planned for future development.

## Project Name
ASTITVA – Empowering Women, Strengthening Communities.
